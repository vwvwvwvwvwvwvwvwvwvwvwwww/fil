# Деплой на [Railway](https://railway.com/)

## 1. Репозиторий

Подключите проект к Railway: **New Project → Deploy from GitHub** (или загрузка репозитория).

## 2. Сборка

В корне есть **`Dockerfile`**. В настройках сервиса выберите деплой из Docker (Railway обычно подхватывает его сам).

Если используете **Nixpacks** вместо Docker: в переменных окружения может понадобиться образ с инструментами сборки для `better-sqlite3` и `bcrypt` — надёжнее оставить **Dockerfile**.

## 3. Сеть и порт

Railway подставляет **`PORT`** — приложение уже читает его в `src/index.js`. Слушает **`0.0.0.0`** (по умолчанию).

Проверка жизни: **`GET /health`**.

## 4. Переменные окружения (обязательно задать в Railway)

| Переменная | Назначение |
|------------|------------|
| `SECRET_KEY` | Длинная случайная строка (JWT), не оставляйте значение по умолчанию. |
| `ADMIN_EMAIL` | Первый сотрудник-панель (создаётся при первом старте, если нет в БД). |
| `ADMIN_PASSWORD` | Пароль для `ADMIN_EMAIL`. |
| `STAFF_ACCOUNTS_PASSWORD` | Общий пароль для сидов сотрудников (Семикина и др.), если используете `seedStaffAccounts`. |
| `VOLUNTEER_DEMO_PASSWORD` | Пароль демо-волонтёров (при первом создании БД). |

Опционально: `VK_ACCESS_TOKEN`, `STAFF_ENTRY_PATH`, `DATABASE_URL`, `LOG_FILE=-` (только лог в консоль Railway).

## 5. База SQLite и данные

По умолчанию файл БД: **`data/app.db`** (относительно корня приложения).

На Railway **файловая система контейнера сбрасывается** при пересборке, если не подключён **Volume**.

- В панели сервиса: **Settings → Volumes → Add Volume**.
- **Mount path:** `/app/data`  
- Оставьте `DATABASE_URL=sqlite:///./data/app.db` (как в `.env.example`).

Тогда БД и сиды сохраняются между деплоями.

Загрузки изображений лежат в **`static/uploads`** — при необходимости добавьте второй volume на `/app/static/uploads` или вынесите хранение в объектное хранилище (отдельная доработка).

## 6. HTTPS и cookies

При наличии переменных **`RAILWAY_ENVIRONMENT`** / **`RAILWAY_PROJECT_ID`** приложение само включает **`trustProxy`** и флаг **`Secure`** у cookie (см. `src/config.js`).

Отключить принудительно: `COOKIE_SECURE=0`, `TRUST_PROXY=0`.

## 7. После деплоя

Откройте выданный Railway URL, проверьте главную и вход в панель **`/admin/login.html`**.

Сиды (демо-события, волонтёры, сотрудники) выполняются при старте, если записей ещё нет — первый запуск после пустого volume может занять несколько секунд.
